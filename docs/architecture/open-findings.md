# Open findings

Review findings deliberately **not** fixed before implementation started. Each was real; each concerned a feature that did not exist yet, so it was cheaper to resolve against real code than against speculative design.

Blocking findings — those affecting F01a, F01b, F01c or the graded minimum — were fixed and are not listed here.

**Rule:** a feature's spec must clear every finding tagged to it before that feature is implemented.

**The shipment is complete**, so the register has been walked against the code rather than against the specs that claimed to close things. A struck row names what closed it. A row that survives says what its current state actually is — several were resolved *in a specification* and not in code, and one (O-52) had been recorded as shipped by three consecutive features while the mapping it described did not exist. The `Blocks` column reads `—` once a finding is closed; a finding tagged to **F12** stays open and stays tagged, because F12 is deferred rather than cancelled and its specification is exactly the artifact a later session inherits (design §5).
