# Raw SQL, ExecuteUpdate and ExecuteDelete all live in the Relational assembly, which features cannot
# currently reach at all (VC-01). The ban exists to catch the day someone adds that reference to make
# one call work: raw SQL reinstates L-04 (DEC-06), ExecuteUpdate bypasses the audit interceptor and
# ExecuteDelete hard-deletes, defeating soft delete (VC-11).
T:Microsoft.EntityFrameworkCore.RelationalQueryableExtensions;No raw SQL, ExecuteUpdate or ExecuteDelete in features. Add a named method to IDbContext instead (DEC-06, DEC-14).
T:Microsoft.EntityFrameworkCore.RelationalDatabaseFacadeExtensions;No raw SQL in features. Add a named method to IDbContext instead (DEC-06).

M:Microsoft.EntityFrameworkCore.EntityFrameworkQueryableExtensions.IgnoreQueryFilters``1(System.Linq.IQueryable{``0});Disables soft delete wholesale; EF 8 has no selective form.
