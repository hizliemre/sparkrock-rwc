# produces a ban that never fires and a file that reads as though it does. Banning the whole
# extension class cannot miss, and nothing here legitimately needs it: ExecuteDelete hard-deletes
# past soft delete, ExecuteUpdate bypasses the audit interceptor, and raw SQL reinstates the legacy
# injection class.
